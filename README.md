# OCTAVE · 현악기 정밀 튜너

크로마틱 + 기타 · 베이스 · 우쿨렐레 · 바이올린 · 비올라 · 첼로 · 콘트라베이스 · 만돌린 · 밴조를 지원하는 웹 튜너.

**사용하기:** https://won2070-commits.github.io/octave-tuner/

- 음정 감지: McLeod Pitch Method(NSDF) + FFT 가속 자기상관 + 포물선 보간 (오차 0.01센트 수준)
- 스트로브 링 디스플레이(회전 정지 = 정음) + 스프링 바늘 게이지 + 센트 추이 그래프
- 자동 줄 감지 / 수동 잠금, 기준음 발생기, A4 캘리브레이션(415–466Hz), 카포/이조, 도레미 표기
- 메트로놈(30–260 BPM, 탭 템포, 2/4~6/8)
- 단일 HTML, 의존성 0. 마이크는 https(또는 localhost)에서만 동작합니다.

로컬 실행: `node server.cjs` → http://localhost:5214
